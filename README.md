A make.fun bounty entry. A home Wi-Fi router excuses itself for dying at the climax of a movie — with one line of text.

`main.py` writes the router's confession to `/output/entry.txt`. The angle: the router is not apologising for a failure. It glimpsed the killer's face two seconds before the audience did and chose to die rather than let the spoiler through — a smug little secret, told in the router's own voice.

Run it with:

```sh
python3 main.py
```

It honours `MAKEFUN_OUTPUT_DIR` (default `/output`), writes the file directly with `open("wb")` and `chmod 0644`, and uses only the Python standard library.
